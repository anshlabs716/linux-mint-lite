## 📖 About

**Linux Mint Lite** is a lightweight version of **Linux Mint XFCE** with unnecessary applications and bloat removed.

The goal is simple:

> ⚡ Keep Linux Mint XFCE lightweight, clean, and useful without filling the system with software that isn't needed.

It is designed for users who want the familiar Linux Mint experience while keeping the installation as lean as possible.

---

## ✨ Features

- 🐧 Based on **Linux Mint XFCE**
- 🪶 Lightweight and minimal
- 🧹 Unnecessary applications removed
- 🚫 No unnecessary bloat
- ⚡ Focused on performance
- 🖥️ XFCE desktop environment
- 🛠️ Easy to customize
- 💻 Suitable for lower-end hardware

---

## 🎯 Philosophy

Linux Mint Lite follows a simple philosophy:

### **No Bloat. No Fluff.**

Instead of installing a huge collection of applications that may never be used, the system focuses on providing a lightweight base that users can customize themselves.

Install what **you** need.

Remove what **you** don't.

---

## 🖥️ Desktop Environment

Linux Mint Lite uses **XFCE** as its desktop environment.

XFCE provides:

- ⚡ Low resource usage
- 🪶 Lightweight desktop experience
- 🛠️ Extensive customization
- 🖥️ Traditional desktop layout
- 💻 Good performance on older hardware
